    口径与技术细节（选读）

    口径：本页提供三种「相似商品」的定义，右上角可切换：

    • ItemCF · 物品余弦：把「用户 × 商品」购买矩阵转置，商品成为行向量 （分量 = 各用户累计购买数量）。相似度 = 两个商品行向量的余弦值， 即「被同一批用户、以相近数量购买」的程度；与相似用户用的是同一张矩阵，行列互换。
    • CBOW 嵌入 / Skip-gram 嵌入：把每一笔订单（InvoiceNo）当作一个句子、 订单内去重的商品当作词，训练商品向量（Item2Vec，见 README 阶段五）。 两种方法分别用 CBOW（用篮内上下文预测商品）与 Skip-gram（用商品预测篮内上下文）， 向量余弦 = 两件商品「经常被放进同一订单一起买」的程度，偏向系列 / 成套搭配。

    相似度条按 0–1 真实刻度绘制；三种方法的分数不可互比（ItemCF 更容易出现 “只被 1–2 人买过”带来的虚高甚至满格 1.00，CBOW 分值整体偏高而 Skip-gram 偏保守）。

    • 同系列换款式/配色 —— 如 JUMBO BAG 的不同印花、红/白心形茶蜡台，三种方法一般都能找到。
    • 同主题搭配品 —— ItemCF 找“同一买家画像”，嵌入方法找“同一订单成套”的搭配。
    • 注意噪声：ItemCF 对低支持共现给分虚高；嵌入方法对从未同单出现的两个爆款会误判。 改进方向见「总结与分析」及 README 阶段五。
