## 0. 任务与评分口径（确证）

- 数据 `train.csv`（2009-12-01 ~ 2010-10-31，332,848 行 → 清洗 326k，3,941 用户 / 3,950 商品）。交付 = 给固定候选集
  `sample_candidates.csv`（**58,205 对 / 736 用户 / 2,690 商品**，含 15.1% 历史已购对）每对打 `user_id,item_id,score`，
  score 越大越推荐，**必须全覆盖**。提交无限次、榜保留最佳、师生同一评分。
- **老师评分标准（2026-09-09 组长告知，探针证实）**：
  `综合分 = 0.40×GAUC + 0.40×NDCG@10 + 0.20×Recall@10`，全为**逐用户列表类指标**（每人自己候选行排序后 top10 计分，再对用户平均）。
- 两条独立探针（`cand-probe-rank` / `cand-probe-block`，各 0.6347 ≈ 基线）先于公式锁死口径：**纯排序、只看数值序、逐用户内部序 macro**——
  跨用户无权重、分数绝对值无关。⇒ 优化目标=把真命中推到每人前 10；user 恒定特征对排序无效，只做 pair / item×user / 候选上下文级。

## 3. 探针/方法论结论（按可信度排序，都是花真榜分买的）

1. **评分口径 = 逐用户列表指标**（probe A/B + 公式）：锁定后所有特征/加权决策都该对齐每人 top-K，而非全局 AUC。user 恒定特征无效。
2. **本地代理只可信到"同类模型族内选方向"**：v2/v3/LR 近窗 4 次跨 4 位小数复现方向（gAUC_m 作为同族选型目标获实证）；
   **跨归纳偏置不可信**——FM 本地碾压（rec@10 .295 vs LGB .216）上板 **0.5448 << 0.6368 崩溃**（v4-FM 教训）。
3. **近顶噪声地板**：榜分散布 .7774-.7782（宽 ~.0008，噪声 ±.0004-8）**淹没本地 OOF ≤.0003 的一切差异**；
   v6 领跑含约一半运气成分（榜保留最佳所以算数）。OOF +.0001 级改动板上不可解析；追 0.7845（+~.006）需要真新信号，非旋钮扰动。
4. **池化选权在真榜不迁移**：按组长"≈全局池化 AUC"信息重选权（XGB 抬到 .55）本地 pooledAUC .8883，板 **.7774 < v6**——真榜奖励 LR 侧重一侧。
   即使后来拿到精确复合公式，本地 8 种聚合口径**没有任何一种复现真榜序**（全把 v7-pooled 排第一，板上它最差）。
5. **LR 轴板盲 + 板上见顶**：本地复合随 LR 权单调降（反对 LR 更重），板上三连发 LR.375→.7774 / **LR.6(v6)→.7782** / LR.75(v12)→.7779 —— 板上 LR 侧重在 ~.6 见顶，"越重越好"只在 .375→.6 段成立、不可单调外推。本地与板方向相反 ⇒ 此轴本地不可裁决，但板上真值峰恰好也在 ~.6（v6 所处位置）。
6. **rubric 对齐的模型方向是死的**：LGBMRanker(lambdarank 直接优化组内 NDCG) 本地复合 .56346 < v6 .58429（低 .021）——pointwise+eq-group 融合已被充分优化。
7. **新特征轴第一批发也空**：5 个 v3 特征（复购周期/类目动量/7天脉冲）同折同配方 44 vs 49 严格 A/B，融合 gAUC_m −.0010 / 复合 −.0004 双负（scripts/61/62，wide_v2 参考块逐位复现 v6 证可比）。
8. **最近月价值（最重要的正发现）**：加旧月份 ≈ 无用（v8-ext 5→9 月净零），**删最近训练月 ≈ 灾难**（丢 Oct 的对照跌 .0079）——Nov 泛化信号高度集中在 cut 前最近月。机制层解释：这是 B2B 批发商，忙季=9-10 月囤货 ramp（见 §5 #3）。

**结构赌注季沉淀（可复用的判断工具）**：
- 退化门禁：换归纳偏置前先看单分量强度——"正交但弱"的分量 = 只减不加。
- 归因对照：赌注同时改了 N 个变量就补 N−1 个对照 serve，别让一个 confound 背锅（#2 的教训）。
- 前提诊断：赌"数据里不存在的时间结构"前先花 10 分钟跑描述统计——12 月对该批发商是平月（Dec09 = 1.02× 月均行），
  真圣诞货峰值在 **2010-10**（67.7k units，12 月只占全年 9.1%），商品级 Dec 倾斜是首月伪影。强负证据应被采信。

## 5. 为什么 v6 就是这题的"顶"（复盘）

- **~7 条轴穷尽**：特征 / 树族 / 加权（三种）/ 训练窗（LR 近 2 月最优）/ 超参 / 选权口径（gAUC_m > pooled > 复合 8 口径）/ 训练池深度（5→9 月），本地复合锁死 .871-.872，榜分锁死 .778 ± 噪声。
- **rubric 公布后四条本地路全空**：精确复合 8 口径不复现 anchor 序、LGBMRanker −.021、LR 轴板盲、新特征批一 −.0010。
- **三次跨界试探全负且可解释**：ALS（构造弱）、H≥2（丢最近月）、季节性（无 12 月结构）——每个失败都反证 v6 恰好站在"该数据唯一有信号的地方"：**cut 前最近训练月**上的**平滑近窗线性 + 去相关树**。
- v6 配方 = LGB(组等权,全月)×.1 + XGB(组等权,全月)×.3 + LR(组等权×spw,**最近2月**)×.6，44 特征，cut 2010-11-01，全局百分位秩融合。

## 6. 方法/工程沉淀（跨题可带走）

1. 榜单类竞赛的**口径先于模型**：两个廉价探针（纯排序？逐用户？）就把优化目标钉死，省掉一整类白工。
2. **代理只能给同族选型**：跨族（FM/ALS）的代理优势是幻觉；同族内跨 4 位小数可复现（gAUC_m）。
3. **噪声地板意识**：到了近顶，所有 .000N 级的"改进"都是重新洗牌；要质变只能找真新信号。上板免费（榜保留最佳）时，判据是"这一发是不是在测一个不依赖本地代理的真假设"。
4. **结构赌注纪律**：前提可诊断的先诊断（如 #3），改多个变量就补对照（如 #2），弱分量不硬烧（如 #1）。失败也要记录——每个负结果都在给最终配方做强度测试。
5. 工程可复现：SEED=42；BLAS 锁 1 线程 + 排序建词表（OPENBLAS/MKL/OMP/NUMEXPR_NUM_THREADS=1）跨进程逐位可复现（曾踩坑：set 迭代序 + BLAS 多线程会让指标漂移）；所有产物写新文件、不覆盖旧答辩链。
