# 实验记录：老师点名模型族 · 轻量组烧写（FM 上线，2026-09-08）

## 动机
v3（LGB c1+macro，0.6368）后，老师点了若干模型族让分别/组合测试：
**LR / XGBoost / FM**（轻量组，无老师代码、需自装自写），DeepFM / 双塔 / DIN（深度组，无 torch，暂缓）。
用协议 B 代理在**同一份**数据上横向对比谁更该出 v4。

## 方法
- 脚本 `25_bakeoff_light_models.py`：Sep→Oct 主窗（9 月训练→10 月测试池 200,241 行，865 用户）；
- 脚本 `26_backtest_aug.py`：Aug→Sep 复验窗（8 月训练→9 月测试池 281,579 行，同构整月平移）；
- 各模型同吃 **macro 用户加权 × scale_pos**，逐用户 top-k macro 评测（对齐探针锁定的口径）；
- numpy FM：自写二阶因子分解机，user/item 低秩嵌入 + 33 稠密特征二阶交互，全量批量 Adam
  （k=16, lr=0.1, steps=800, wd=1e-5, seed=42；`OPENBLAS` 等锁 1 线程 + 排序建词表 ⇒ 逐位可复现）。
- 集成：逐用户百分位 rank 加权平均（等权 + FM 主导 0.7/0.85）。

## 为什么 FM 碾压、集成全输（机理）
训练正样本 = 用户在标签月买过的商品对；FM 直接学 user×item 亲和。打分时（fp 已含标签月）
它把"上个月买过、很可能下月复购"的商品顶到最前。树模型的正样本在训练特征里 owned=0
（fp<标签月），学不到这对亲和，只能靠 33 维画像相似度泛化 ⇒ rec@10 差 ~2.5×、ndcg@10 差 ~2.4×。
FM 与树对真阳性的顶置**错位** ⇒ 任何 rank 融合（0.5 甚至 0.85FM）都稀释 FM ⇒ **集成不作数，v4=FM 单点**。
代理与生产结构同构（生产=Oct 标签训练→Nov 打分，打分 fp 含 Oct），优势是真实复购建模而非代理假象。

## 上线动作（v4）
`scripts/27_build_fm.py` 复刻 v3 生产协议（训练 cut=10-01 全量、打分 cut=11-01 用尽整份 train.csv），
同参数 FM 训练（92s）→ `outputs/candidate/sample_submission_cand-fm-v1.csv`（58,205 行，确定性可复现）。
权重/models/candidate_cand-fm-v1.npz + meta。**分数用全精度 float**：FM sigmoid 饱和会让 round(6)
把 ~1.9 万行压成 0.0、~8.8 千行压成 1.0，每用户 top10 并列均值 6.4/9（会钝化顶置排序）；
全精度下并列均值降到 2.7/9 且集中在该用户特征完全相同的冷行（模型本就无法区分），top 无饱和块
（max prob <1.0）。代理上 FM 的领先本就是在这种并列下算出来的 ⇒ 不额外加抖动。

## ⚠️ 实测结论（2026-09-08）：代理优势未传导，v4 崩
`cand-fm-v1` 老师综合分 **0.5448，大幅低于 v3 0.6368**（榜保留 v3）。

- 协议 B 代理此前只在 **LGB 同类配置间**被验证过能挑方向（v2/v3）。FM 是**不同归纳偏置**
  （把一切押在"标签月买过 → 下月复购"的 pair 亲和），其代理优势建立在代理测试窗 = 紧邻下一月、
  正样本含大量紧邻复购上。
- 老师真实任务的正样本/候选构成不匹配这一假设 ⇒ FM 顶置错位，且因其预测极端集中
  （大量候选 ~0、顶置极少），崩得比树（平缓分布、逐步退）更狠 ⇒ 0.5448 << 0.6368。
- **教训（下次先读）**：
  1. 代理只能用于**同类模型/同类归纳偏置**间的相对选择；换模型族在代理上赢 ≠ 真榜会赢。
  2. 若要再试 pair 亲和类模型（DeepFM/双塔/DIN 同理），必须先解决"真实正样本是不是紧邻复购"的
     疑问（用代理改口径验证：正样本去掉"上月已购"类复购后再比，FM 还赢不赢），别直接烧提交。
  3. FM 输出全精度已上线但无济于事——问题在归纳偏置/标签假设，不在 tie 精度。
